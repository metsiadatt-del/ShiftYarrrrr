ShiftYar — نسخه ۲۵
====================

اصلاح نسخه ۲۵: پالت رنگی، پس‌زمینهٔ شیشه‌ای، بهینه‌سازی موبایل، آیکون نصب و قابلیت «ریست شیفت‌ها برای علی عادلی» اضافه یا جایگزین شده‌اند. کش به نسخه ۲۵ تغییر کرده است؛ پایین برنامه باید «نسخه ۲۵» دیده شود. تمام فایل‌ها را باهم منتشر کنید؛ اطلاعات مرورگر را پاک نکنید. ۷۸ آزمون موفق؛ مرورگر، نصب واقعی و Lighthouse آزمایش نشده‌اند.

این بسته کامل است؛ فایل‌های index.html، app.bundle.js، styles.css، sw.js، manifest.webmanifest، favicon.ico، پوشه assets و پوشه icons باید باهم منتشر شوند.

تغییرات نسخه ۲۵
۱. پالت جدید (نیلی ملایم + فیروزه‌ای آرام)
- Tokens روشن: bg #EEF1F7، surface rgba(255,255,255,.55)، primary #5B6FE0، accent #2FA79B، danger #D46A6A و…؛ تاریک: bg #0E1220، primary #8396F2، accent #52C7BA و…
- مقدار دقیق همهٔ توکن‌ها در دو بلوک :root و :root[data-theme=dark] در ابتدای styles.css است.
- تم با [data-theme] روی html؛ پیش‌فرض ترجیح سیستم از طریق @media(prefers-color-scheme:dark) و انتخاب کاربر در localStorage (shiftyar-theme). انتقال رنگ ۰.۳ ثانیه.
- توکن‌های مشتق (primary-filled، danger-ink، success، deputy، future، control-border، focus-ring) برای حفظ کنتراست حداقل AA. رنگ متن روی سطوح شفاف با ترکیب روی بدترین پس‌زمینه در tests/appearance.test.js ریاضی بررسی می‌شود.
- هیچ رنگ ثابتی خارج از tokens در CSS نیست؛ آزمون آن را کنترل می‌کند.

۲. شیشه‌ای
- .glass/کارت‌ها/فیلدها/dialog/نوار تب با backdrop-filter: blur(14px) saturate(140%) و -webkit- نسخه.
- body::before/::after لکه‌های بزرگ fixed با blur(80px) تا شیشه دیده شود.
- Focus: border رنگ primary + box-shadow 0 0 0 3px primary-soft؛ خطا: border danger؛ غیرفعال: opacity .5؛ placeholder از text-muted.
- Fallback: @supports not ((backdrop-filter:blur(1px)) or (-webkit-backdrop-filter:blur(1px))) روی surface-strong.

۳. بهینه‌سازی بصری و موبایل
- مقیاس تایپوگرافی (۲۰–۲۲/۷۰۰، ۱۶–۱۷/۶۰۰، ۱۴–۱۵/۴۰۰، ۱۲–۱۳ کمکی، line-height 1.6) با متغیرهای فاصله ۴/۸/۱۲/۱۶/۲۴/۳۲.
- دکمه اصلی پر، ثانویه شیشه‌ای، خطرناک با danger-soft؛ active: scale(.98).
- موبایل عمودی: padding کارت‌ها ۱۲px، فیلدهای کوتاه دوستونی، تب‌های برنامه ماه sticky، فاصلهٔ پایین برای نوار شناور و safe-area.
- دسکتاپ و موبایل افقی چیدمان قبلی را با پوستهٔ جدید دارند.

۴. آیکون نصب
- icons/icon.svg منبع؛ PNG: icon-192/512 (any)، icon-maskable-192/512 (maskable، نماد در ۸۰٪ مرکزی)، apple-touch-icon.png ۱۸۰، favicon-16/32.png، favicon.ico در ریشه.
- manifest.webmanifest: نام فارسی کوتاه، short_name ShiftYar، display standalone، dir rtl، lang fa، theme_color #5B6FE0، background_color #EEF1F7 و چهار آیتم icons.
- index.html: link manifest، apple-touch-icon، faviconها، دو meta theme-color با media light/dark، apple-mobile-web-app-*.
- همهٔ آدرس‌ها نسبی‌اند تا GitHub Pages درست کار کند؛ sw.js کش shiftyar-shell-v25 را دوباره می‌سازد و کش قدیمی را پاک می‌کند.
- ساخت دوبارهٔ آیکون‌ها: node tools/icons.js (بدون وابستگی جدید؛ رسترایزر و PNG encoder داخلی).

۵. ریست شیفت‌ها برای علی عادلی
- انتهای تب «ماه نامه» کارت «عملیات خطرناک» با دکمهٔ دقیق «ریست شیفت‌ها برای علی عادلی».
- اگر در ماه نمایش‌داده‌شده (ماه انتخاب‌شده در همین تب) شیفتی برای او نباشد، دکمه غیرفعال و متن «شیفتی برای این ماه ثبت نشده» نمایش داده می‌شود.
- مودال تأیید: «آیا مطمئن هستید؟ تعداد [N] شیفت ثبت‌شدهٔ علی عادلی در [ماه و سال] حذف خواهد شد. این عمل قابل بازگشت نیست.» با دکمه‌های «انصراف» و «بله، حذف شود».
- شناسایی او با id قائم‌مقام: نام کامل برابر «علی عادلی» یا ترکیب نام+نام خانوادگی، پس از trim و یکسان‌سازی ي/ی، ك/ک و فاصله‌های تکراری.
- فقط شیفت‌های همان شخص در همان ماه (بر اساس ساعت داخل ماه، مثل بقیهٔ گزارش‌ها) حذف می‌شوند؛ افراد دیگر و ماه‌های دیگر دست‌نخورده‌اند. حذف اتمیک در localStorage ذخیره می‌شود و پس از رفرش پایدار است.
- تقویم، جدول و جمع ساعت‌ها فوراً render می‌شوند؛ toast «[N] شیفت حذف شد» با دکمهٔ «بازگردانی» به مدت ۶ ثانیه. خطای ذخیره‌سازی فقط toast خطا نشان می‌دهد و داده تغییر نمی‌کند.

به‌روزرسانی سایت و نصب
۱. قبل از هر به‌روزرسانی، از پروفایل پشتیبان JSON بگیرید.
۲. ZIP را استخراج و همه فایل‌ها، پوشه assets و پوشه icons را در همان مسیر قبلی سایت جایگزین کنید. آدرس سایت را تغییر ندهید؛ اطلاعات محلی به مرورگر و مبدأ وابسته‌اند.
۳. برای GitHub Pages، فایل‌ها در ریشه مخزن باشند و Settings > Pages روی شاخه و مسیر انتشار درست تنظیم شود. این بسته چیزی را روی GitHub منتشر یا push نکرده است.
۴. سایت را آنلاین روی HTTPS باز کنید، تا «آمادهٔ استفاده آفلاین» صبر کنید، برنامه را ببندید و دوباره باز کنید. پایین صفحه باید «نسخه ۲۵» دیده شود. اگر نسخه قدیمی دیده می‌شود، انتشار/بارگیری هنوز کامل نشده؛ اطلاعات سایت را پاک نکنید.
۵. اگر آیکون نصب قبلی روی صفحهٔ هوم/دسکتاپ هنوز قدیمی است، برنامهٔ نصب‌شده را باز کنید و یک بار آنلاین بارگذاری کنید؛ سیستم‌عامل ممکن است تا فرصت بعدی آیکون کش‌شده را نگه دارد. تنها راه فوری، حذف و نصب دوباره است که بدون پشتیبان JSON توصیه نمی‌شود.
۶. آیفون: Safari > Share > Add to Home Screen.
۷. میان‌بر معمولی فایل HTML در ویندوز با نصب PWA فرق دارد؛ برای آیکون آن، favicon.ico را در مسیر ثابت نگه دارید و Properties > Shortcut > Change Icon را انتخاب کنید. لینک دانلود ICO داخل پروفایل هم هست. وب‌سایت نمی‌تواند آیکون میان‌بر موجود دسکتاپ را به‌اجبار تغییر دهد.

تست قابلیت ریست
۱. یک قائم‌مقام با نام «علی عادلی» بسازید و یک یا چند شیفت برایش در ماه جاری ثبت کنید؛ برای فرد دیگری در همان ماه و برای خود علی عادلی در ماه قبل هم شیفت بگذارید.
۲. تب «ماه نامه» را باز کنید. پایین صفحه کارت «عملیات خطرناک» باید تعداد شیفت‌های قابل حذف همین ماه را نشان دهد.
۳. دکمه را بزنید؛ متن تأیید باید تعداد درست و نام ماه/سال را نشان دهد. «انصراف» هیچ تغییری نمی‌دهد.
۴. «بله، حذف شود» را بزنید: تقویم و جمع‌ها فوراً به‌روز می‌شوند، toast «[N] شیفت حذف شد» می‌آید و دکمه غیرفعال می‌شود.
۵. صفحه را رفرش کنید؛ شیفت‌ها باید حذف‌شده بمانند. با انتخاب ماه قبل، همان شیفت‌های قدیمی و فعال بودن دکمه دیده می‌شوند.
۶. بلافاصله پس از حذف (۶ ثانیه) «بازگردانی» را بزنید؛ شیفت‌ها برمی‌گردند.

اجرای محلی و آفلاین
index.html را پس از استخراج کامل می‌توان مستقیم باز کرد؛ bundle مستقل است. برای نصب و ذخیره‌سازی قابل اتکا از HTTPS استفاده کنید؛ localStorage در file:// بین مرورگرها متفاوت است.
بعد از یک بار بارگیری کامل آنلاین، تقویم، ثبت/ویرایش، برنامه ماه، محاسبات، فونت‌ها و خروجی‌ها اینترنت لازم ندارند. بار اول روی دستگاه تازه به اینترنت نیاز دارد. PDF از چاپ مرورگر و گزینه Save as PDF تهیه می‌شود.
در نسخه محلی، فایل‌ها همراه برنامه هستند اما نصب service worker از file:// امکان‌پذیر نیست و آیکون نصب هم ارائه نمی‌شود؛ نشان وضعیت این تفاوت را اعلام می‌کند.

جریان کار
- تقویم: فضای خالی روز ثبت شیفت را باز می‌کند؛ انتخاب شیفت موجود برای ویرایش است و تعداد شیفت در موبایل جزئیات روز را باز می‌کند.
- ثبت ثابت: پیش‌فرض هفته شنبه تا جمعه تاریخ انتخابی؛ انتخاب روزها و ساعات و گزینه اختیاری تعمیم به تمام هفته‌های همان ماه.
- برنامه ماه مستقل از شیفت‌های شخصی است: الگوها و پرسنل و مسئول هر شیفت؛ نمای روزانه و تمام‌صفحه با حفظ پیمایش.

قواعد داده و محاسبه
- داده در localStorage با کلید shiftyar-v1 است؛ حساب آنلاین یا همگام‌سازی ندارد. انتخاب تم مستقل با shiftyar-theme ذخیره می‌شود.
- حذف اطلاعات مرورگر/برنامه ممکن است داده‌ها را حذف کند. بازیابی پشتیبان کل داده را جایگزین می‌کند. اطلاعات محلی رمزگذاری نشده‌اند؛ پشتیبان را عمومی منتشر نکنید.
- تاریخ ذخیره ISO، نمایش شمسی و امروز به وقت تهران است.
- پایان کمتر یا برابر شروع یعنی روز بعد؛ ساعت برابر یعنی ۲۴ ساعت.
- تداخل یک شخص از جمله عبور از نیمه‌شب ممنوع است؛ ثبت تکراری اتمیک انجام می‌شود.
- عادی ۰۶ تا ۲۲، شب ۲۲ تا ۰۶؛ تعطیل مقدم است.
- گزارش پرسنل کل شیفت را به ماه شروع نسبت می‌دهد؛ گزارش مالی شخصی ساعت عبوری از ماه را تقسیم می‌کند.
- تعطیلات از منبع ثانویه آفلاین است؛ تعطیلات قمری آینده را با اعلام رسمی کنترل و در برنامه اصلاح کنید.

خروجی و آزمون
XLSX و DOCX واقعی، CSV امن، JSON، HTML و PDF از چاپ. JSON گزارش با پشتیبان کامل متفاوت است.
۷۸ آزمون Node/DOM/VM موفق؛ شامل پالت و کنتراست دو تم، شیشه و fallback، تایپوگرافی/لمس/فوکوس، چیدمان موبایل، manifest و آیکون‌ها، کش نسخه ۲۵ و سه سناریوی ریست (حذف محدود + undo، پایداری پس از reload و ماه دیگر، غیرفعال بودن بدون شخص منطبق). core.js تغییر نکرده است.
آزمون مرورگر، اسکرین‌شات، نصب واقعی و Lighthouse در این محیط انجام نشده‌اند. بررسی CSS ساختاری است و تضمین بصری دستگاه واقعی یا نمرهٔ PWA نیست.

توسعه (Node.js 20 یا جدیدتر)
  npm ci --ignore-scripts
  npm run bundle
  npm run check
  npm test
  node tools/icons.js   # فقط اگر آیکون‌ها را تغییر دادید
بیلد کوچک esbuild؛ وابستگی جدیدی اضافه نشده است. node_modules را منتشر نکنید. مجوز فونت‌ها و کتابخانه‌ها در assets و vendor موجود است.

فایل‌های تغییرکرده
- styles.css: پالت جدید، tokens مشتق، شیشه، fallback، تصحیح کنتراست، موبایل فشرده، تب sticky، کارت danger-zone.
- app.js و app.bundle.js: theme-color دوگانه، danger zone و مودال/حذف/undo ریست، toast اصلاح‌شده، نسخه ۲۵ در پایین صفحه.
- index.html، manifest.webmanifest، sw.js: آیکون‌های جدید، metaهای نصب، نسبت‌های مسیر، کش v25.
- icons/*، favicon.ico: خروجی‌های آیکون از icons/icon.svg.
- icon-art.js (جدید)، tools/icons.js (جدید)، assets/app-icon.js (حذف‌شده): آیکون SVG سربرگ به کد منتقل شد و ابزار ساخت آیکون‌ها اضافه شد.
- tests/appearance.test.js، tests/entry.test.js، tests/pwa.test.js، tests/ui.test.js: به‌روزرسانی و آزمون‌های جدید. README.txt: راهنمای تحویل.
